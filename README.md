# NTP-KeyEventLogger
## Kullanılan Teknolojiler
- C# / .NET Windows Forms
## Kurulum ve Çalıştırma Adımları

1. Bu depoyu yerel bilgisayarınıza klonlayın:
   `git clone https://github.com/250542008-sanat/NTP-KeyEventLogger.git`
2. Proje klasörüne girin ve `NTP-KeyEventLogger.sln` dosyasını Visual Studio ile açın.
3. Üst menüden "Başlat" (Start) butonuna basarak veya `F5` tuşu ile uygulamayı derleyip çalıştırın.

## Uygulamanın Temel Özellikleri

* **Anlık Tuş Yakalama:** `KeyDown` eventi kullanılarak klavyeden basılan tuşları anında tespit etme.
* **Zaman Damgası:** Yakalanan her tuşu, basıldığı saat ve dakika bilgisiyle birlikte ListBox üzerinde gösterme.
* **Oturum Yönetimi:** Kayıt işlemini başlatma, durdurma ve ekrandaki listeyi temizleme butonları.
* **Dosyaya Kaydetme (StreamWriter):** Elde edilen tuş verilerini programın çalıştığı dizine `TusKayitlari.txt` adında bir metin belgesi olarak kalıcı şekilde kaydetme.
